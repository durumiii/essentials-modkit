# 공개 안내문 초안 (2026-08-03)

repo 공개(`gh repo create`)와 갤러리 게시는 사용자 결정 게이트다. 이 문서는
그 시점에 바로 쓸 수 있는 텍스트 초안만 담는다 — 실제 게시는 하지 않았다.

## repo 공개 시 About / 짧은 소개

RPG Maker 기반 Essentials 팬게임(포켓몬 Z, Wishing Star 등)의 모드를 표준
카드 하나로 다루는 도구. 얹기·빼기·진단·격리를 CLI와 GUI 양쪽으로 제공한다.

## 갤러리 안내문 초안

포켓몬 Z 한글패치를 쓰다가 "이전 패치 위에 새 패치를 얹었더니 이상해졌다"는
제보가 여러 번 들어왔어요. 대개는 옛 패치가 남긴 파일이 새 패치와 부딪혀서
생기는 문제였는데, 그걸 사람이 눈으로 찾기는 어려웠습니다.

그래서 만든 게 modkit이에요. 게임 폴더를 진단하면 지금 상태가 원본 그대로인
파일, 알려진 모드가 남긴 파일, 그리고 어디서 왔는지 알 수 없는 "외래" 파일로
나뉘어 나옵니다. 외래 파일이 있으면 지우는 대신 게임 폴더 안
`_quarantine/<날짜>/` 폴더로 옮겨 두기만 해서, 잘못 판단했다 싶으면 통째로
되돌릴 수 있어요.

포켓몬 Z 한글패치 v5부터는 배포판에 이 진단용 지문(`manifest.json`)을 함께
넣었습니다. 패치를 받은 뒤 modkit으로 게임 폴더를 열어 보면 v5가 제대로
깔렸는지, 옛 패치 흔적이 남았는지를 직접 확인할 수 있어요.

창을 띄우려면 Windows 10/11의 Edge WebView2 런타임이 있어야 해요. 윈도우 11에는
기본으로 들어 있고, 없다는 안내가 뜨면 마이크로소프트 공식 다운로드에서 받아
깔면 됩니다.

같은 도구로 모드를 보관소에서 꺼내 오고(harvest), 얹고 빼는 것도 됩니다 —
포켓몬 Z든 다른 Essentials 팬게임이든, 모드가 `mod.json` 카드 규약을 따르기만
하면요. 자세한 카드 규약과 설치 계약은 repo의 `SPEC.md`에 정리해 뒀습니다.
